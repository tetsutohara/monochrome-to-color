# Overview

An application that converts monochrome images into color images.  
Colorization is based on [this work](https://github.com/richzhang/colorization).

## Quickstart

```bash
git clone https://github.com/tetsutohara/monochrome-to-color
cd monochrome-to-color
docker compose up
```

## Planned Features

- **Download Button**: Option to download the colorized image directly from the UI.
